# Anki 题库生成器 V1.2 — AI 接手指南

> 把这份文档 + 代码包丢给任何一个 AI 助手，它就能按你的需求生成同款 Anki 题库练习包。

## 一、30 秒了解本系统

输入：题库 Excel（「打印」sheet：总序号/序号/一级纲要/题目分类/题型/题干/选项/答案）+ 用户导出的学习进度 .apkg
输出：可导入 Anki 的 .apkg 卡片包（交互式答题、动态乱序、注释全覆盖）

## 二、给 AI 的标准指令模板

```
1. 读取工作区里的《中级员工试题.xlsx》「打印」sheet 作为题库
2. 读取我的进度包（.apkg 内 collection.anki21b，zstd 解压 → SQLite，
   从 revlog 表统计每道题答错次数；ease=1 即答错）
3. 运行 scripts/gen_anki_enhanced.py 生成完整强化包
   或 scripts/gen_wrong_focus.py 只生成错题专项练习
4. 保证：GUID 与我集合一致（导入零新增卡）、模型 ID 对齐、卡组名对齐
```

## 三、核心规则（AI 必须遵守）

1. **动态乱序**：单选/多选选项每次出现都重新洗牌（V10.2 延迟检测法：
   setTimeout(0) 时若 DOM 有 #resultBanner 即为背面→复用正面顺序；
   否则必为新一轮正面→强制重新洗牌）。判断题固定 A正确/B错误不洗牌。
2. **判分时序**：洗牌 setTimeout(0) → 判分 setTimeout(1)，
   否则背面 showAnswer 被模板重置为原始字母导致答对误判。
3. **注释无字母**：所有提示盒用选项原文指代，绝不写"选B"这类字母（乱序会变）。
4. **GUID 稳定**：genanki.guid_for("v10_single/multi/judge", 题干, 原始答案)；
   包内完全重复题只保留一条（零新增卡）。
5. **模型 ID 对齐**：从用户集合 SELECT DISTINCT mid FROM notes 动态读取。
6. **卡组名对齐**：新 schema 内部层级符是 \x1f，匹配前归一化为 ::。

## 四、注释盒三层结构（全部在 RemarkHTML 字段，正面干净）

| 盒 | 触发 | 内容 |
|---|---|---|
| 🔴 红盒·真实错题 | revlog 中 ease=1 次数≥1 | 记忆锚点(题干关键词↔正确项原文绑定) / 最强迷惑项(字面相似度+数值相近) / 📌正确组合全文 / 🔗同概念关联(题干相似+共用选项+⚡正误反转+跨题型) / ✅正确说法📖出处💡说明 / 本机计数器 |
| 🟣 紫盒·预测高危 | 未错但风险分≥40 | 风险原因(题型基线47%/主题错误率/数值相近/措辞陷阱宜可以vs必须严禁/与错题共用选项) + 同红盒全套 |
| 🔵 蓝盒·快记 | 其余全部 | 题干头→正确项原文锚点 + 出处 + 关联提醒 |

## 五、强关联引擎（全库两两检测）
- 信号①选项共用（含正误反转）②题干相似(bigram Jaccard) ③跨题型加成
- 并查集归并概念家族 → 卡组内家族成员相邻排序（家族内 多选→判断→单选）
- 跨题型内容关联：判断题题干⊃某单选/多选正确项原文；多选组合≈某单选正确项
- 笔记标签：易错·错N次 / 预测易错 / 低风险 / 概念家族N题 / 部分选多选

## 六、环境
```bash
pip install genanki openpyxl   # Python 3.14 验证通过
# 或使用随附 py-libs 目录（genanki/openpyxl/pyyaml/chevron 离线版）：
set PYTHONPATH=py-libs路径
python scripts/gen_anki_enhanced.py 题库.xlsx [输出.apkg] [--sheet 打印]
python scripts/gen_wrong_focus.py            # 错题专项（需先有 progress_analysis.json）
```

## 七、版本历史

## 八、已知边界
- 本机答错计数存 localStorage，多设备不同步（Anki 不给卡片开放复习日志）
- 学习进度需用户从 Anki 导出带调度的 apkg 才能分析
